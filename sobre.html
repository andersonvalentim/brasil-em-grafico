De onde vêm os números

Todo número do site vem de um órgão público oficial. Aqui você vê quem mede cada coisa, de quanto em quanto tempo e onde achar os dados originais.

Os números são atualizados automaticamente.Todo dia, o site busca os dados nas bases oficiais abaixo. Quando uma fonte está fora do ar, o site mantém o último número que conseguiu buscar. Se algum número aparecer como “dados ilustrativos”, é porque a fonte ainda não pôde ser lida.

As fontes oficiais

Como ler os gráficos

Todo gráfico segue a mesma ordem: primeiro a pergunta, depois o número grande com uma frase, depois o gráfico e, por último, os detalhes recolhidos. Quem aprende uma vez entende o site inteiro.

O que cada cor quer dizer

  • Azul: o dado
  • Laranja-urucum: o seu estado ou o valor mais recente
  • Linha tracejada: a média do Brasil ou a meta
  • Cinza: os outros estados
  • Listras: sem dado

A cor nunca diz se algo é bom ou ruim. Quem diz é o texto, com “subiu” ▲ ou “caiu” ▼.

Poucos tipos de gráfico, sempre iguais

  • Número grande: o valor principal, sempre com a unidade.
  • Linha: como algo mudou com o tempo.
  • Barras deitadas: para comparar estados, sempre começando do zero.
  • Ano a ano: cada item numa linha e cada ano numa coluna; a barra vai para a direita quando subiu e para a esquerda quando caiu.
  • Faixas: quantos estados ficam em cada faixa de valor.
  • 100 pessoas: “em cada 100, quantas…”, para porcentagens.

Não usamos pizza, 3D nem eixo cortado, porque eles enganam o olho.

Antes de usar um número, confira

Questionar um número é legítimo, e cobrar qualidade de uma instituição pública faz parte da democracia. Uma boa análise começa pela informação: o que o número mede, de quando ele é e de onde ele vem. Todo cartão deste site mostra essas três coisas.

  1. O que o número mede?

    Desemprego, desalento e subutilização, por exemplo, contam grupos de pessoas diferentes. Abra “Entenda este número” em cada cartão.

  2. De quando é e de quem?

    Um trimestre não é o mesmo que a média do ano, e o Brasil não é o mesmo que o seu estado. O período aparece embaixo de cada gráfico.

  3. De onde vem?

    Todo número tem fonte oficial e um link para a tabela original, onde dá para conferir e baixar os dados.

Declaração de acessibilidade

Feito para todas as pessoas

  • Seguimos as regras de acessibilidade WCAG 2.2, nível AA.
  • Todo gráfico tem um botão “Ouvir”, que lê a resposta em voz alta, e um botão “Ver em tabela”.
  • O botão “Aa Texto maior” aumenta as letras. O site também funciona com zoom de 200%.
  • Tudo funciona pelo teclado, com o foco sempre visível.
  • O site é leve e funciona em celulares simples e com internet fraca.
